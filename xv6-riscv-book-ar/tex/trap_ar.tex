\chapter{المصايد واستدعاءات النظام}
\label{CH:TRAP}

تحدث \textbf{المصيدة} (Trap) عندما يحتاج المعالج إلى تحويل السيطرة والتنفيذ بصورة قسرية من البرمجية الحالية إلى النواة.
وتحدث المصايد في الحالات التالية:
\begin{enumerate}
  \item استدعاء نظام (System Call): عندما تنفذ عملية مستخدم تعليمة \texttt{ecall}.
  \item استثناء (Exception): عندما تنفذ تعليمة غير صالحة أو يحدث خطأ في الذاكرة (مثل القسمة على صفر أو خطأ الصفحة).
  \item مقاطعة عتادية (Interrupt): عندما يرسل جهاز عتادي (مثل مؤقت الساعة أو القرص الصلب) إشارة طلب خدمة.
\end{enumerate}

يقدم هذا الفصل الآليات العتادية والبرمجية لمعالجة المصايد في RISC-V، وكيفية التعامل مع المصايد القادمة من فضاء المستخدم وفضاء النواة.

\section{عتاد المصايد في RISC-V}
\label{sec:riscv_trap_machinery}

يحتوي كل معالج في RISC-V على مجموعة من السجلات العتادية الخاصة بوضع المشرف (Supervisor CSRs) للتحكم في المصايد:
\begin{itemize}
  \item \texttt{stvec} (Supervisor Trap Vector Base Address Register): يحتوي على عنوان دالة معالجة المصايد في النواة.
  \item \texttt{sepc} (Supervisor Exception Program Counter): يحفظ فيه العتاد عنوان التعليمة التي حدثت عندها المصيدة.
  \item \texttt{scause} (Supervisor Cause Register): يحفظ فيه العتاد سبب وقوع المصيدة (استدعاء نظام، مقاطعة، أو استثناء معين).
  \item \texttt{sstatus} (Supervisor Status Register): يحتوي على رايات الحالة مثل \texttt{SIE} (تفعيل المقاطعات) و \texttt{SPP} (الوضع السابق قبل المصيدة).
  \item \texttt{stval} (Supervisor Trap Value Register): يحفظ القيمة المصاحبة للخطأ (مثل العنوان غير الصالح عند خطأ الصفحة).
\end{itemize}

عند حدوث مصيدة، يقوم عتاد RISC-V تلقائيًا بالخطوات المباشرة التالية:
\begin{enumerate}
  \item إذا كانت المصيدة مقاطعة عتادية وراية \texttt{SIE} معطلة، يتم تجاهل المقاطعة.
  \item يحفظ المعالج قيمة عداد البرنامج الحالي \texttt{pc} في \texttt{sepc}.
  \item يحفظ المعالج الوضع الحالي (U-mode أو S-mode) في راية \texttt{SPP} داخل \texttt{sstatus}.
  \item يكتب المعالج كود السبب في \texttt{scause}.
  \item يعطل المقاطعات بمسح الراية \texttt{SIE}.
  \item ينسخ وضع المشرف (S-mode) ليكون الوضع الحالي.
  \item يحمل قيمة \texttt{stvec} إلى عداد البرنامج \texttt{pc} للقفز فورًا إلى معالج النواة.
\end{enumerate}

\section{المصايد القادمة من فضاء المستخدم}
\label{sec:traps_user_space}

عند حدوث مصيدة أثناء تنفيذ برنامج مستخدم، يتطلب الأمر تبديل جدول الصفحات وسجلات المعالج والمكدس بأمان تام دون تمكين المستخدم من التلاعب بالحالات النواتية.

تُدار العملية في \texttt{xv6} بواسطة صفحة المنصة القافزة \texttt{TRAMPOLINE} المتواجدة في نفس العنوان الافتراضي في كلي جدولَي الصفحات:
\begin{enumerate}
  \item يضمن العتاد التحويل إلى \texttt{stvec} المحتوي على عنوان \texttt{uservec} داخل كود التجميع في \texttt{kernel/trampoline.S}.
  \item تقوم \texttt{uservec} بحفظ كافة سجلات المعالج الـ 31 الخاصة بالمستخدم داخل هيكل \texttt{trapframe} الخاص بالعملية.
  \item تحمل \texttt{uservec} عنوان مكدس النواة للعملية، وعنوان جدول صفحات النواة إلى \texttt{satp}.
  \item تقفز \texttt{uservec} إلى الدالة \texttt{usertrap()} المكتوبة بلغة C في \texttt{kernel/trap.c}.
\end{enumerate}

تتفحص \texttt{usertrap()} السجل \texttt{scause}:
\begin{itemize}
  \item إذا كان السبب استدعاء نظام (\texttt{scause == 8})، تزيد \texttt{epc} بمقدار 4 لتخطي تعليمة \texttt{ecall} وتستدعي \texttt{syscall()}.
  \item إذا كانت مقاطعة عتادية، تستدعي \texttt{devintr()}.
  \item خلاف ذلك، يكون استثناءً غير متوقع، فتنهي النواة العملية فورًا وتطبع رسالة خطأ.
\end{itemize}

بعد انتهاء المعالجة، تعود \texttt{usertrap()} عبر \texttt{usertrapret()} التي تستدعي \texttt{userret} لإعادة استرجاع سجلات المستخدم وتحديث \texttt{satp} بالعودة إلى فضاء المستخدم وتنفيذ \texttt{sret}.

\section{الكود البرمجي: تنفيذ استدعاءات النظام}
\label{sec:code_calling_syscalls}

تقوم الدالة \texttt{syscall()} المحددة في \texttt{kernel/syscall.c} بقراءة رقم استدعاء النظام المخزن في سجل المستخدم \texttt{a7} (\texttt{p->trapframe->a7}).

تتحقق \texttt{syscall()} من صحة الرقم وفهرسته داخل جدول الدوال \texttt{syscalls[]}:
\begin{lstlisting}
void
syscall(void)
{
  int num;
  struct proc *p = myproc();

  num = p->trapframe->a7;
  if(num > 0 && num < NELEM(syscalls) && syscalls[num]) {
    p->trapframe->a0 = syscalls[num]();
  } else {
    p->trapframe->a0 = -1;
  }
}
\end{lstlisting}
يُخزن المخرج الناتج عن دالة استدعاء النظام داخل سجل المستخدم \texttt{a0} ليقرأه البرنامج.

\section{الكود البرمجي: وسائط استدعاءات النظام}
\label{sec:code_syscall_args}

تمرر برامج المستخدم وسائط استدعاءات النظام عبر سجلات المعالج القياسية (\texttt{a0} إلى \texttt{a5}).
توفر النواة دوال مساعدة لاستخراج هذه الوسائط بأمان في \texttt{kernel/syscall.c}:
\begin{itemize}
  \item \texttt{argint(n, \&ip)}: جلب الوسيط رقم $n$ كعدد صحيح (32-bit integer).
  \item \texttt{argaddr(n, \&ip)}: جلب الوسيط رقم $n$ كعنوان ذاكرة (64-bit address).
  \item \texttt{argstr(n, buf, max)}: جلب سلسلة نصية من فضاء ذاكرة المستخدم ونسخها بأمان في ذاكرة النواة باستخدام \texttt{fetchstr()}.
\end{itemize}

ولأن فضاء ذاكرة المستخدم منفصل عن فضاء النواة، توفر النواة الدوال \texttt{copyin()} و \texttt{copyout()} لنقل البيانات بين فضاء العناوين الافتراضي للعملية وفضاء النواة مع التحقق من صحة المداخل.

\section{المصايد القادمة من فضاء النواة}
\label{sec:traps_kernel_space}

عندما تنفذ النواة كودًا في وضع المشرف (S-mode) وتحدث مقاطعة أو استثناء، يختلف التعامل قليلاً:
\begin{enumerate}
  \item جدول الصفحات هو بالفعل جدول صفحات النواة، ومكدس النواة مثبت بالفعل.
  \item يتم تحويل \texttt{stvec} ليرير إلى الدالة \texttt{kernelvec} في \texttt{kernel/kernelvec.S}.
  \item تحفظ \texttt{kernelvec} سجلات المعالج على مكدس النواة الحالي وتستدعي \texttt{kerneltrap()} المحددة في \texttt{kernel/trap.c}.
  \item بعد معالجة المقاطعة أو الاستثناء، تسترجع \texttt{kernelvec} السجلات من المكدس وتنفذ \texttt{sret}.
\end{enumerate}

\section{العالم الحقيقي}
\label{sec:real_world_trap}

تستخدم المعالجات الحديثة آليات مصايد معقدة تدعم المتجهات المباشرة (Vectored Interrupts) بحيث ترتبط كل مقاطعة بعنصر محدد في جدول المتجهات لتسريع الاستجابة. كما تتطلب آليات الأمن المتطورة مثل Meltdown و Spectre معالجة دقيقة للغاية لصفحات القفز وعزل جداول الصفحات لتجنب تسريب السجلات المخبئية.

\section{تمارين}
\label{sec:exercises_trap}

\begin{enumerate}
  \item تتبع خطوات نقل القيمة من سجل المستخدم \texttt{a0} إلى متغير النواة في استدعاء النظام \texttt{sys\_write}.
  \item قم بتعديل \texttt{xv6} لدعم معالجة خطأ الصفحة لتقديم صفحة صفرية عند الحاجة (Null Page Guard).
\end{enumerate}
