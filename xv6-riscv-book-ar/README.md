# مشروع الترجمة العربية المعتمدة لكتاب xv6 RISC-V (صيغة Typst)
## xv6: a simple, Unix-like teaching operating system (Arabic Translation)

مرحباً بك في مشروع الترجمة العربية الأكاديمية الكاملة لكتاب أنظمة التشغيل الخاص بمعهد ماساتشوستس للتكنولوجيا (**MIT 6.1810 / 6.828**):
**"xv6: نظام تشغيل تعليمي بسيط شبيه بـ Unix"**
(المؤلفون: روس كوكس، فرانس كاشوك، وروبيرت موريس).

تم إنجاز هذه الترجمة بالكامل بصيغة **Typst** الحديثة، وباتّباع المعايير الأكاديمية والمهنية المعتمدة في **كلية الألسن (جامعة عين شمس)** وشركات الترجمة وتعريب البرمجيات العالمية (Localization & CAT Workflows).

---

## 📌 منهجية الترجمة والأدوات المعتمدة

1. **اعتماد صيغة Typst الأكاديمية الفائقة**:
   - تم التخلي عن صيغ LaTeX و Quarto لصالح صيغة **Typst** الحديثة التي توفر أداءً أعلى في البناء، ودعماً أصيلاً للغة العربية والاتجاه من اليمين إلى اليسار (`dir: rtl`)، وإبراز الشفرات البرمجية بلغة C و RISC-V Assembly.

2. **معجم المصطلحات الموحد (TermBase - TB - النسخة 11 الصارمة)**:
   - تم إنشاء معجم مصطلحي موحد في `glossary/GLOSSARY.md` و `glossary/termbase.json` يضبط جميع مفاهيم أنظمة التشغيل ومعمارية RISC-V (مثل: `Page Table` -> جدول الصفحات، `System Call` -> استدعاء النظام، `Process` -> عملية، `Job` -> مهمة، `Task` -> مهمة فرعية، `TLB` -> مخزن الترجمة المؤقت).

3. **ذاكرة الترجمة (Translation Memory - TM)**:
   - حفظ الجمل والأنماط التكرارية والجداول في قاعدة بيانات التنسيق `tm/translation_memory.json` لضمان المطابقة الدلالية والتكامل عبر جميع الفصول.

4. **التكسير المعنوي للأسطر (Semantic Line Breaking)**:
   - تقسيم النصوص في ملفات `.typ` على مستوى المفاهيم والجمل المستقلة لضمان سهولة القراءة وتتبع الشفرات.

## 📂 بنية المشروع وشجرة الملفات (مجلد Typst)

```text
xv6-riscv-book-ar/
├── README.md                 # هذا الملف الموضّح للمشروع والمنهجية
├── glossary/
│   ├── GLOSSARY.md           # معجم المصطلحات العربي التفصيلي وشروط الصياغة
│   └── termbase.json         # المعجم المصطلحي بصيغة JSON المفتوحة
├── tm/
│   └── translation_memory.json # ذاكرة الترجمة المقطعة (Segmented TM)
└── typst/                    # مشروع الكتاب الكامل المترجم بصيغة Typst
    ├── book_ar.typ           # الملف الرئيسي الجامع لكافة الفصول
    ├── template/             # مجلد القوالب والمكتبات المساعدة
    │   ├── listings.typ      # مكتبة إبراز الشفرات البرمجية والرموز
    │   ├── listings-languages.typ # معجم لغات البرمجة C و RISC-V
    │   ├── fix-bidi.typ      # معالجة اتجاه النصوص البرمجية المدمجة
    │   └── fancyhdr.typ      # مكتبة الترويسات والتذييلات
    └── chapters/             # مجلد الفصول المترجمة والمرتبة رقمياً
        ├── 00_acks.typ       # الشكر والتمهيد
        ├── 01_unix.typ       # الفصل 1: واجهات نظام التشغيل
        ├── 02_first.typ      # الفصل 2: تنظيم نظام التشغيل
        ├── 03_mem.typ        # الفصل 3: جداول الصفحات
        ├── 04_trap.typ       # الفصل 4: المصايد واستدعاءات النظام
        ├── 05_pgfault.typ    # الفصل 5: استثناءات أخطاء الصفحات
        ├── 06_interrupt.typ  # الفصل 6: المقاطعات وبرامج التشغيل
        ├── 07_lock.typ       # الفصل 7: الأقفال والتزامن
        ├── 08_sched.typ      # الفصل 8: المجدول وتنقيل السياق
        ├── 09_sleep.typ      # الفصل 9: النوم واليقظة
        ├── 10_fs.typ         # الفصل 10: نظام الملفات
        ├── 11_log.typ        # الفصل 11: طبقة سجل العمليات
        ├── 12_lock2.typ      # الفصل 12: إعادة فحص الأقفال
        └── 13_sum.typ        # الفصل 13: الخاتمة والتطورات
```

## 🛠️ كيفية بناء الكتاب في Typst

لبناء كتاب PDF كامل ومترجم بلغة Typst:
```bash
cd typst
typst compile book_ar.typ book_ar.pdf
```
