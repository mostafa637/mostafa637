# مشروع الترجمة العربية لكتاب xv6 RISC-V
## xv6: a simple, Unix-like teaching operating system (Arabic Translation)

مرحباً بك في مشروع الترجمة العربية الكاملة لكتاب أنظمة التشغيل الخاص بمعهد ماساتشوستس للتكنولوجيا (**MIT 6.1810 / 6.828**):
**"xv6: نظام تشغيل تعليمي بسيط شبيه بـ Unix"**
(المؤلفون: روس كوكس، فرانس كاشوك، وروبيرت موريس).

تم إنجاز هذه الترجمة باتباع المعايير الأكاديمية والمهنية الدقيقة المعمول بها في **كلية الألسن (جامعة عين شمس)** وشركات الترجمة وتعريب البرمجيات العالمية (Localization & CAT Workflows).

---

## 📌 منهجية الترجمة والأدوات المعتمدة

1. **معجم المصطلحات الموحد (TermBase - TB)**:
   تم إنشاء معجم مصطلحي موحد في `glossary/GLOSSARY.md` و `glossary/termbase.json` يضبط جميع مفاهيم أنظمة التشغيل ومعمارية RISC-V (مثل: `Page Table` -> جدول الصفحات، `System Call` -> استدعاء النظام، `Spinlock` -> قفل التناوب، `Trampoline` -> صفحة المنصة القافزة، `Hart` -> مسار العتاد).

2. **ذاكرة الترجمة (Translation Memory - TM)**:
   تم حفظ الجمل والأنماط التكرارية والجداول في قاعدة بيانات التنسيق `tm/translation_memory.json` لضمان المطابقة الدلالية والتكامل عبر جميع الفصول.

3. **النبرة الأكاديمية والأسلوب**:
   - الاعتماد على الفصحى المعاصرة الرصينة مع المحافظة على النبرة التوضيحية المباشرة والمحكمة للمؤلفين في MIT.
   - **التضمين المزدوج**: ذكر المصطلح العربي متبوعاً بالمصطلح الإنجليزي عند الورود الأول.
   - **الرمزية والشيفرات البرمجية**: المحافظة الكاملة على أسماء الدوال C، والمتغيرات، ومسجلات المعالج RISC-V (`fork`, `exec`, `satp`, `trampoline`, `spin_lock`, `a0`, `a7`, `sepc`, `stvec`) باللغة الإنجليزية كما هي لمنع أي التباس لدى الطالب أو الباحث.

## 🛠️ كيفية البناء والاستخدام

### 1. بناء كتاب PDF باستخدام LaTeX:
```bash
cd tex
xelatex book_ar.tex
makeindex book_ar
xelatex book_ar.tex
```

### 2. بناء موقع ويب تفاعلي باستخدام Quarto:
```bash
cd qmd
quarto render
```
