# RDRAND reference

مصادر المرحلة: [Felix Cloutier — RDRAND](https://www.felixcloutier.com/x86/rdrand) و[Intel DRNG Software Implementation Guide](https://www.intel.com/content/www/us/en/developer/articles/guide/intel-digital-random-number-generator-drng-software-implementation-guide.html).

في 64-bit mode تكون الصيغة الافتراضية لـRDRAND بعرض 32-bit، ويحوّل REX.W العملية إلى 64-bit. الصيغة ذات 16-bit تستخدم سجلاً 16-bit. إذا نجح مصدر العشوائية تكتب التعليمة قيمة صالحة في الوجهة وتضبط CF=1؛ وإذا لم تتوفر قيمة تكتب صفراً بالعرض المحدد وتضبط CF=0. في الحالتين تُجبر OF وSF وZF وAF وPF إلى الصفر، ولا تتغير البتات غير المرتبطة بهذه المجموعة. يجب على البرنامج الضيف فحص CF وإعادة المحاولة عند الفشل.

تنفيذ Pure Go لا يستطيع افتراض وجود RDRAND hardware في المضيف، لذلك يحتاج MachineState64 إلى مصدر قابل للحقن للاختبار. التنفيذ الافتراضي يستخدم crypto/rand.Read دون CGo، بينما يمكن للاختبار تمرير provider يعيد قيمة ثابتة أو خطأ لمحاكاة النجاح والفشل. عند فشل provider يجب تطبيق دلالة المعالج: تصفير الوجهة بالعرض الصحيح، CF=0، وتصفير OF/SF/ZF/AF/PF.
