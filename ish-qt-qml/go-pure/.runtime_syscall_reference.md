# Linux runtime syscall reference

## Sources

- https://man7.org/linux/man-pages/man2/set_tid_address.2.html — `set_tid_address()` stores the calling thread's clear-child-TID pointer and returns the caller's TID. On thread exit, the kernel clears the guest word and performs a futex wake on that address.
- https://linux.die.net/man/2/futex — futex operations wait for or wake waiters associated with a user-space 32-bit word. `FUTEX_WAIT` compares the current word with the expected value and blocks; `FUTEX_WAKE` wakes up to the requested number of waiters.
- https://docs.kernel.org/userspace-api/rseq.html — `rseq()` registers or unregisters a per-thread restartable-sequence area. A compatibility implementation may accept registration and retain the address/length/flags without attempting kernel-managed preemption aborts when the guest is single-threaded.
- https://man7.org/linux/man-pages/man2/nanosleep.2.html — `nanosleep()` reads a two-word timespec, suspends execution for the requested interval, and optionally writes the remaining interval on interruption. A non-interrupted sleep returns zero.
- https://man7.org/linux/man-pages/man2/gettid.2.html — `gettid()` returns the caller's thread ID, distinct from the process ID when multiple threads exist.

## Implementation decisions for this Pure-Go guest

- The x86-64 guest is currently single-threaded. `gettid` returns `Context64.TID`, falling back to `PID` when TID is zero.
- `set_tid_address` validates a guest pointer when nonzero, stores it in the context, and returns the guest TID. No host thread exit path is synthesized yet; this avoids claiming child-thread lifecycle semantics that the current process model does not provide.
- `futex` initially supports private `FUTEX_WAIT` and `FUTEX_WAKE` using a process-local keyed condition-variable table. WAIT validates and compares the guest 32-bit value before blocking; WAKE returns the number of waiters released. Unsupported operations return `ENOSYS` or `EINVAL` rather than silently succeeding.
- `rseq` accepts the standard registration form for a single-threaded guest and rejects unsupported flags/signature combinations with `EINVAL`; unregister (`pointer == 0`, length/flags zero) clears the registration.
- `nanosleep` validates `timespec.tv_nsec` in `[0, 999999999]`, sleeps using Go's monotonic duration, and returns zero on normal completion.
