## Semantics used here

For x86-64, `mmap` receives a 64-bit address hint, length, protection flags, mapping flags, signed 32-bit fd, and a 64-bit file offset. Anonymous mappings require no file backing; file offsets must be page aligned. `mprotect` requires a page-aligned address and applies protection to all pages intersecting the requested range. `munmap` removes a page-aligned nonzero range. The Pure-Go implementation intentionally keeps the existing iSH fake address-space policy and maps unsupported host-only flags to the existing errno behavior.

`lseek` receives a signed 64-bit offset and returns a signed 64-bit file position. `SEEK_SET`, `SEEK_CUR`, and `SEEK_END` are supported through the descriptor's `Seeker`; negative resulting positions are rejected with `EINVAL`, and invalid/non-seekable descriptors return the existing descriptor errno. The handler must preserve the full 64-bit result rather than truncating it to the i386 32-bit range.
