# PBLENDVB reference

Sources:
- https://www.felixcloutier.com/x86/pblendvb
- https://www.read.seas.harvard.edu/~kohler/class/aosref/IA32-1.pdf (Intel 64 and IA-32 Architectures Software Developer's Manual, Volume 1)

Legacy PBLENDVB is the 128-bit SSE4.1 form with encoding `66 0F 3A 0E /r`. The destination and first source are the same XMM register (`xmm1`), the second source is an XMM register or m128 memory operand, and the mask is implicitly architectural XMM0. The most-significant bit of each XMM0 byte selects the corresponding result byte: mask bit 1 copies the source byte; mask bit 0 preserves the destination byte. The instruction does not modify XMM0 and does not modify RFLAGS. It is not a VEX instruction.

The JIT must snapshot destination/source/mask before writing because XMM0 may alias the destination or source. For each byte i, use `result[i] = source[i]` when `mask[i]&0x80 != 0`, otherwise retain the original destination byte. The memory form reads exactly 16 bytes from the effective address and faults through the existing memory path.
