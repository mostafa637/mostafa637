# PSHUFW reference

المصدر: [Felix Cloutier — PSHUFW](https://www.felixcloutier.com/x86/pshufw)

## الصيغة والترميز

الصيغة legacy هي `0F 70 /r ib PSHUFW mm1, mm2/m64, imm8`. الوجهة هي ModRM.reg من نوع MMX، والمصدر هو ModRM.r/m من نوع MMX أو ذاكرة 64-bit، ثم immediate بحجم 8-bit. في 64-bit mode يوسّع REX.R مجموعة السجل التي يستخدمها الترميز وفق تعريف x86asm؛ يجب اختبار bytes المقبولة فعلياً بدلاً من افتراض صيغة غير مدعومة.

## الدلالة

يقسم immediate إلى أربعة حقول من بتين. كل حقل يختار كلمة 16-bit من المصدر، ثم تُكتب الكلمات الأربع في الوجهة:

```text
DEST[15:0]  := (SRC >> (ORDER[1:0] * 16))[15:0]
DEST[31:16] := (SRC >> (ORDER[3:2] * 16))[15:0]
DEST[47:32] := (SRC >> (ORDER[5:4] * 16))[15:0]
DEST[63:48] := (SRC >> (ORDER[7:6] * 16))[15:0]
```

يمكن تكرار أي كلمة مصدر أكثر من مرة. لا تتغير RFLAGS، ولا توجد immediate operands أخرى أو upper XMM lanes في صيغة MMX. يجب أخذ snapshot للمصدر قبل الكتابة عندما تتطابق الوجهة والمصدر.

## قرار التنفيذ

سيُضاف dispatch strict يطلب destination MMX، source MMX أو memory بعرض 8 bytes، وimmediate 8-bit. سيُقرأ المصدر من `MachineState64.MMX` أو memory، ثم يُبنى `uint64` جديد من الكلمات الأربع ويُكتب إلى MMX destination، مع استدعاء `EnterMMX()` وتقدم RIP. أخطاء memory ستُعاد كما هي للحفاظ على fault propagation.
