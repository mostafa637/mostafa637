# PCMPGTQ وPACKUSDW

## PCMPGTQ

مرجع: [Felix Cloutier — PCMPGTQ](https://www.felixcloutier.com/x86/pcmpgtq).

نسخة legacy SSE تقارن كل qword موقّع في destination مع qword المناظر في source. إذا كان qword في destination أكبر من source، تُكتب `0xffffffffffffffff`، وإلا تُكتب `0`. المصدر الثاني XMM أو m128، ولا تتأثر flags.

```text
IF SRC1[63:0] > SRC2[63:0]
    DEST[63:0] := FFFFFFFFFFFFFFFFH
ELSE
    DEST[63:0] := 0
FI
IF SRC1[127:64] > SRC2[127:64]
    DEST[127:64] := FFFFFFFFFFFFFFFFH
ELSE
    DEST[127:64] := 0
FI
```

## PACKUSDW

مرجع: [Felix Cloutier — PACKUSDW](https://www.felixcloutier.com/x86/packusdw).

نسخة legacy SSE تحول أربعة signed dword من destination وأربعة signed dword من source إلى ثمانية unsigned word في destination، مع unsigned saturation: القيم الأقل من صفر تصبح `0`، والقيم الأكبر من `0xffff` تصبح `0xffff`، والقيم الوسطية تُحفظ كـword منخفض. لا تتأثر flags، ولا تتأثر البتات العليا من سجل YMM المقابل؛ نموذج MachineState64 يخزن XMM فقط.

```text
for each signed dword x in DEST then SRC:
    if x < 0: result = 0
    else if x > 0xffff: result = 0xffff
    else: result = uint16(x)
```

الاختبارات يجب أن تغطي register، memory، REX.R، والقيم السالبة والصفرية والقيم فوق `0xffff`، مع إثبات بقاء RFLAGS دون تغيير.
