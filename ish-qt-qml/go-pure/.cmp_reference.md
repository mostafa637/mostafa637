## Legacy SSE semantics

CMPPD/CMPPS compare each packed lane from the destination XMM operand (A) with the source XMM/memory operand (B), using imm8 bits 2:0 as the legacy predicate. A true comparison writes an all-ones lane mask; false writes zero. CMPPD has two 64-bit lanes and CMPPS has four 32-bit lanes. Legacy CMPSD/CMPSS compare only the low lane and preserve the destination XMM upper bits above bit 63/31 respectively.

The unordered relation is true when either operand is NaN; ordered is true only when neither operand is NaN. The legacy predicates are:

| imm3 | Predicate | Result on ordered A/B | Result if unordered |
|---:|---|---|---|
| 0 | EQ_OQ | A == B | false |
| 1 | LT_OS | A < B | false |
| 2 | LE_OS | A <= B | false |
| 3 | UNORD_Q | false | true |
| 4 | NEQ_UQ | A != B | true |
| 5 | NLT_US | !(A < B) | true |
| 6 | NLE_US | !(A <= B) | true |
| 7 | ORD_Q | true | false |

The newer predicate encodings 8..31 are documented by Intel for VEX/EVEX, but legacy SSE uses bits 2:0; the implementation should use the low three bits for CMPPD/CMPPS/CMPSD/CMPSS. For signaling predicates, actual hardware may raise an FP invalid exception for QNaN/SNaN; the current Pure-Go JIT has no FP exception delivery path, so result-mask semantics are implemented without introducing a new trap.

The comparisons are source-order sensitive: the first operand is the destination XMM value, and the second operand is the ModRM source. Scalar instructions preserve the destination upper lanes, while packed instructions replace all lanes in the 128-bit XMM destination.
