# PMULLD وPMULDQ

المراجع: [PMULLD](https://www.felixcloutier.com/x86/pmulld:pmullq) و[PMULDQ](https://www.felixcloutier.com/x86/pmuldq)، Felix Cloutier / Intel SDM.

## PMULLD legacy SSE4.1

`PMULLD xmm1, xmm2/m128` يضرب أربعة أزواج من signed 32-bit lanes، ويكتب الجزء الأدنى 32-bit من كل حاصل في lane المناظر. كل حاصل وسيط 64-bit؛ overflow يتجاهل، ولا تتغير flags.

```text
for lane = 0..3:
    temp = SignExtend64(int32(DEST[lane])) * SignExtend64(int32(SRC[lane]))
    DEST[lane] = low32(temp)
```

## PMULDQ legacy SSE4.1

`PMULDQ xmm1, xmm2/m128` يستخدم فقط dword lanes الزوجية 0 و2 من كل مصدر. كل حاصل signed 32×32 ينتج signed 64-bit كامل، ويُكتب في qword lanes 0 و1؛ dword lanes الفردية لا تدخل في الحساب. لا تتغير flags.

```text
DEST[63:0]   = SignExtend64(int32(DEST[31:0]))  * SignExtend64(int32(SRC[31:0]))
DEST[127:64] = SignExtend64(int32(DEST[95:64])) * SignExtend64(int32(SRC[95:64]))
```

هذه المرحلة تنفذ legacy XMM فقط؛ لا تضيف VEX/AVX أو YMM/EVEX.
