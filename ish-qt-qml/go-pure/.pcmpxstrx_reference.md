# PCMPxSTRx reference findings

Sources: [Intel SDM string opcode section](https://john-lazzaro.github.io/class/special/pdf/string_opcodes.pdf), [PCMPESTRI](https://www.felixcloutier.com/x86/pcmpestri), [PCMPESTRM](https://www.felixcloutier.com/x86/pcmpestrm), [PCMPISTRI](https://www.felixcloutier.com/x86/pcmpistri), [PCMPISTRM](https://www.felixcloutier.com/x86/pcmpistrm), and [SIMD string comparison reference](https://www.officedaytime.com/simd512e/simdimg/str.php?f=pcmpestri).

The Intel SDM defines BoolRes with the first index belonging to xmm2/m128 and the second to xmm1. Equal Any compares equality and aggregates OR across all xmm1 elements for each xmm2 position. Ranges compares each xmm2 element with adjacent xmm1 pairs as `xmm2[j] >= xmm1[i] AND xmm2[j] <= xmm1[i+1]`, with i even. Equal Each compares diagonal pairs. Equal Ordered evaluates each candidate offset j by ANDing comparisons of xmm2[k] with xmm1[i] over the complete needle range.

The valid/invalid override table is:

| xmm1 element | xmm2 element | Equal Any/Ranges | Equal Each/Ordered |
|---|---|---:|---:|
| invalid | invalid | false | true |
| invalid | valid | false | false |
| valid | invalid | false | false |
| valid | valid | normal comparison | normal comparison |

For explicit-length forms, EAX/RAX supplies xmm1 length and EDX/RDX supplies xmm2 length. The absolute length saturates at 16 bytes or 8 words. For implicit-length forms, the first NUL element and all following elements are invalid. Therefore explicit ZF/SF are set when the corresponding saturated length is below the maximum, while implicit ZF/SF are set when a NUL occurs.

Aggregation pseudocode uses `upperBound = 15` in byte mode or `7` in word mode. Equal Any initializes IntRes1 to zero and ORs BoolRes[j,i] across i. Ranges ORs `BoolRes[j,i] AND BoolRes[j,i+1]` across even i. Equal Each sets IntRes1[i] to BoolRes[i,i]. Equal Ordered initializes all result bits to one and, for each candidate start j, ANDs `BoolRes[k,i]` across corresponding elements where the full needle fits; candidate starts that cannot fit remain false through invalid overrides.

Polarity is selected by imm8[5:4]. Positive and masked-positive copy IntRes1. Negative inverts every result bit. Masked-negative inverts IntRes1 only when the corresponding xmm2/m128 element is valid, and copies IntRes1 for invalid xmm2 elements. STRI chooses least/most significant set bit by imm8[6] and writes ECX (zero-extending the 32-bit result), using 16/8 if no bit is set. STRM writes compact IntRes2 in low 16/8 bits when imm8[6]=0, or expands each bit to an all-ones byte/word lane when imm8[6]=1.

Flags are set nonstandardly: CF is IntRes2 != 0, ZF reports an invalid/short xmm2 input, SF reports an invalid/short xmm1 input, OF is IntRes2 bit 0, and AF/PF are reset. The Felix Cloutier pages are an unofficial mechanically separated reference; the Intel SDM remains authoritative.
