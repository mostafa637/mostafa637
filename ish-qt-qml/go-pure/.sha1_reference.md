## Semantics used by the Pure-Go JIT

SHA1NEXTE `xmm1, xmm2/m128` computes `TMP = ROL32(SRC1[127:96], 30)`, stores `DEST[127:96] = SRC2[127:96] + TMP`, and copies the remaining three 32-bit lanes from SRC2 unchanged. In the project XMM byte representation, lane 3 is the architectural bits 127:96 lane.

SHA1RNDS4 selects the SHA-1 Boolean function and constant from `imm8 & 3`, reads `(A,B,C,D)` from destination lanes 3,2,1,0, and reads `(W0+E,W1,W2,W3)` from source lanes 3,2,1,0. Round zero uses the pre-combined `W0+E`; rounds one through three add the carried E value. Each round computes `T = f(B,C,D) + ROL32(A,5) + message + K`, then updates `(A,B,C,D,E) = (T,A,ROL32(B,30),C,D)`. The result is written back as `(A4,B4,C4,D4)` into lanes 3,2,1,0. Neither instruction changes flags.

The four selectors use the SHA-1 constants `0x5a827999`, `0x6ed9eba1`, `0x8f1bbcdc`, and `0xca62c1d6`; selectors 0, 1, 2, and 3 use the choose, parity, majority, and parity functions respectively.
