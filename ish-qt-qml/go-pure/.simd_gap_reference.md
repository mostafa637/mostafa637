# Next SIMD reference findings

Sources: [Felix Cloutier MPSADBW](https://www.felixcloutier.com/x86/mpsadbw), [Intel SSE4 manual MPSADBW overview](https://xem.github.io/minix86/manual/intel-x86-and-64-manual-vol1/o_7281d5ea06a5b67a-296.html), [Felix Cloutier PCLMULQDQ](https://www.felixcloutier.com/x86/pclmulqdq), and [Intel Carry-Less Multiplication paper](https://cdrdv2-public.intel.com/724272/carry-less-multiplication-instruction.pdf).

Legacy 128-bit MPSADBW uses the destination XMM as both first source and destination. imm8[1:0]*32 selects the fixed 4-byte block in the second source; imm8[2]*32 selects the first 4-byte window in the destination source. It computes eight unsigned-byte SAD sums, each comparing the fixed four-byte block against an overlapping four-byte window beginning at destination offsets 0..7 from the selected initial block. Each result is a 16-bit word in XMM0..XMM7; imm8[7:3] is ignored. The first-source/destination snapshot must be read before writing, and the second source may be XMM or m128 memory.

PCLMULQDQ legacy SSE uses the destination XMM as source1 and destination, and XMM/m128 as source2. imm8 bit 0 selects source1 low/high qword; imm8 bit 4 selects source2 low/high qword. The selected 64-bit operands are multiplied carry-less into a 128-bit result: XOR shifted copies of the first operand for every set bit in the second operand, with no integer carries. Other immediate bits are ignored, and only the XMM 128-bit result is written. The Intel reference pseudo-op selections are 0=low*low, 1=high*low, 0x10=low*high, 0x11=high*high.

x86asm v0.30.0 defines MPSADBW and PCLMULQDQ constants and decode tables. SHA1MSG1/SHA1MSG2/SHA256MSG1/SHA256MSG2/SHA256RNDS2 are also present in x86asm but are deferred until these two legacy SSE instructions are complete.
