# ملاحظات مطابقة واجهة iSH iOS

## القياسات الأصلية من Roots.storyboard

- التصميم المرجعي landscape بحجم 736×414.
- جدول الجذور يستخدم grouped table view مع خلفية groupTableViewBackgroundColor.
- شريط التنقل الأصلي أعلى الصفحة، وعنوانه `Filesystems`، وزر الاستيراد في الجهة اليمنى.
- خلية الجذر العادية ارتفاعها 43.6667 نقطة، والنص system 17pt مع هامش أفقي يقارب 20pt، ومؤشر disclosure في الجهة اليمنى.
- خلية الجذر الافتراضي ارتفاعها 55.6667 نقطة؛ عنوان 17pt في y≈9، والوصف 12pt في y≈31.3.
- تفاصيل الجذر تستخدم خلايا grouped بارتفاع 43.6667 نقطة، وخلايا ذات subtitle عند الحاجة.
- شاشة التفاصيل تعرض `Name` بخط 17pt، وحقل الاسم بمحاذاة يمين بخط 14pt، يبدأ بعد هامش يقارب 95pt.
- رابط `Browse Files` يستخدم لون systemBlue وخط system 17pt.

## فروق QML الحالية

- `IOSToolBar.qml` يستخدم ارتفاعًا ثابتًا 48px، بينما شريط iOS القياسي مع safe area/navigation bar أقرب إلى 44pt بالإضافة إلى inset النظام.
- `RootsPage.qml` يستخدم ColumnLayout بهوامش 16px، عناوين 20/18px، وبطاقات مستديرة ارتفاعها 48px؛ هذا يختلف عن grouped UITableView وخلايا 43.7/55.7pt.
- زر الرجوع الحالي نصي `‹ Back`، بينما iOS يستخدم زر navigation back وأيقونة/نصًا بحجم أصغر داخل شريط 44pt.
- قائمة الجذور الحالية تعرض `Use` و`Delete` داخل كل صف، بينما Roots.storyboard يعرض صفًا بسيطًا بمؤشر انتقال، وتكون عمليات الإدارة في صفحة التفاصيل أو action sheet.
- يجب اعتماد نظام قياس مركزي مع scaling حسب devicePixelRatio وsafe-area، ثم استبدال البطاقات الحالية بخلايا grouped ذات ارتفاعات iOS الأصلية.
