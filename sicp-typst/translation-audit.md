## ٦. تفكيك لبس «معامل» (التمريرة الثانية)

«معامل» كانت تُستخدم في الترجمة لخمسة مفاهيم إنجليزية مختلفة، فيلتبس على
القارئ هل المقصود المعمول أم المعلمة أم الوسيط أم العامل أم معامل حسابي.
طُبِّقت قاعدة 2 من القواعد التحريرية (الجدول v12) على الكتاب كله:

| المفهوم | المقابل المعتمد | الظهور قبله ← بعده |
|---|---|---|
| operand | معمول / معمولات | 1 ← 32 |
| parameter (شكلي) | معلمة / معلمات | 0 ← 68 |
| argument (فعلي) | وسيط / وسائط | 392 ← 512 |
| operator | عامل / عوامل (مستقل عن «معامل») | 306 ← 327 |
| coefficient / factor / معاملة بنكية / treatment | «معامل» بلا تغيير | 62 بقايا مشروعة (كانت 297) |

أُضيف للجدول مدخل Operand=معمول/معمولات ليكتمل رباعي القاعدة.

### أ. أمثلة تمييزية قبل/بعد

- 1.1.1: «تعبيرات #emph[المعاملات] على جانبيه» ← «تعبيرات
  #emph[المعمولات] (#en[operands])».
- 1.1.4: «المعاملات (#meta("parameters")) تُستبدل بالوسائط» ← «المعلمات
  تُستبدل بالوسائط» — صار التمييز بين الشكلي والفعلي ظاهرًا في النص نفسه.
- 4.1: «إلى المعاملات والدوال الأوليّة التي تُطبق مباشرة» ← «إلى
  #emph[العوامل] والدوال الأوليّة» (EN: operators).
- 4.4.4: «تأخذان معاملًا مؤجلاً» ← «وسيطًا مؤجَّلًا»؛ «وهو معامل $k$ أقل»
  ← «أقل #emph[بعامل] $k$» (factor).
- 5.2.3: «نولد دالة تنفيذ لكل معامل» ← «لكل معمول».
- 3.1.2: «دالة بدون معاملات ترجع...» ← «دالة بلا #emph[وسائط]» (EN: of
