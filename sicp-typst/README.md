# SICP بصيغة Typst — نسخة Python

تحويل كتاب **Structure and Interpretation of Computer Programs** (نسخة Python) من
مصادر XML الخاصة بمشروع [source-academy/sicp](https://github.com/source-academy/sicp)
إلى كود Typst نظيف ومنظّم في مجلدات.

الناتج كتاب واحد يُبنى بأمر واحد، ويحتوي على الفصول الخمسة
والفهرس وقائمة التمارين والمراجع، بالإنجليزية (`book.typ`) وبالعربية
(`book-ar.typ`).

## البناء

```bash
typst compile book.typ
```

يلزم Typst 0.15 أو أحدث. لبناء فصل واحد فقط:

```bash
typst compile --root . content/chapter1/chapter1.typ
```

كل ملف في `content/` قابل للترجمة بمفرده، لأنه يستورد المكتبة بنفسه.

### مخرجات المُفسِّر

الأسطر المائلة التي «يطبعها» المفسّر في الكتاب تُحسب تنفيذًا فعليًا لبايثون عبر
[calepin](https://typst.app/universe/package/calepin). ترجمة Typst المجردة لا
تنفّذ كودًا، فتظهر هذه المقاطع فارغة على نسخة جديدة من المستودع؛ ولملئها:

```bash
calepin compile book.typ    # أو book-ar.typ
```

ينفّذ calepin كل مقطع مخرجات بجلسة بايثون حقيقية (بنفس دلالات الكتاب: `exec`
فقط، فلا يُطبع شيء لتعبير بلا `print`، ولا شيء عند الخطأ)، ويخزّن النتائج في
`.calepin/` ثم يبني الكتاب بها. بعدها يكفي `typst compile book.typ` لعرض
النتائج المخزّنة دون إعادة تنفيذ. الواجهة `.calepin/calepin.typ` المُودَعة في
المستودع تُستبدل آليًا بـ runtime المولَّد عند أول تشغيل، وتجعل الترجمة المجردة
تعمل من أول نسخة.

## البنية

| المسار | المحتوى |
|---|---|
| `book.typ` | الملف الرئيسي: صفحة العنوان، الفهرس، الفصول، الملاحق |
| `lib/sicp.typ` | نقطة الدخول للمكتبة، تجمّع الملفات الأربعة التالية |
| `lib/book.typ` | تنسيق الصفحة والعناوين والفقرات والحواشي والمراسي |
| `lib/code.typ` | كتل الكود بلغة Python، ومخرجات المفسّر التي ينفّذها calepin |
| `lib/exercise.typ` | التمارين وترقيمها حسب الفصل |
| `lib/index.typ` | الفهرس الهجائي وقائمة التمارين مع أرقام الصفحات |
| `content/chapterN/` | الفصل رقم N، وداخله `sectionM/` لكل قسم وأقسامه الفرعية |
| `content/others/` | المقدمات والمراجع وما يسبق الكتاب ويليه |
| `images/` | 156 صورة للأشكال، بنفس التقسيم الأصلي |
| `tools/` | أدوات التحويل والفحص (ليست جزءًا من الكتاب) |

التقسيم يعكس تقسيم المصدر: `content/chapter2/section3/subsection1.typ` هو
القسم الفرعي 2.3.1، ويضم كل فصل أقسامه عبر `#include`.

## الأدوات

جميع ملفات `content/` **مولّدة**؛ عند الحاجة إلى تعديل، عدّل المحوّل أو `lib/`
لا الملفات الناتجة.

```bash
python3 tools/convert.py --source /path/to/sicp   # إعادة التوليد
python3 tools/check.py                            # ترجمة كل ملف على حدة
python3 tools/check.py chapter3                   # فحص جزء فقط
python3 tools/locate.py content/…/subsection1.typ # تحديد السطر المرفوض
```

| الأداة | الوظيفة |
|---|---|
| `convert.py` | المحوّل: يقرأ XML ويكتب Typst على مرحلتين (جمع العناوين ثم الكتابة) |
| `latex_math.py` | ترجمة رياضيات LaTeX إلى Typst، ونصّها المجرّد لمداخل الفهرس |
| `escape.py` | تهريب المحارف الخاصة في Typst |
| `check.py` | يترجم كل ملف مستقلًا ويعرض كل الأخطاء دفعة واحدة |
| `locate.py` | يحدّد السطر الذي يرفضه Typst بالتنصيف |

المحوّل **حتمي**: التشغيل مرتين يعطي ملفات متطابقة بايتًا ببايت.

## الحالة

- 256 ملفًا (131 إنجليزيًا و125 عربيًا)، جميعها يُترجم منفردًا ومجتمعًا (`256/256`).
- 624 عنوانًا مرجعيًا، **ولا يوجد مرجع معلّق واحد**.
- جرد مقابل المصدر: كل صنف من العناصر مطابق تمامًا بعد استبعاد فروع Scheme
  و`WEB_ONLY` التي تُهمَل عمدًا:

  | العنصر | المصدر | الناتج |
  |---|---|---|
  | الأشكال | 97 | 97 |
  | التمارين | 356 | 356 |
  | الحواشي | 332 | 332 |
  | العناوين الفرعية | 174 + 3 | 174 + 3 |
  | الاقتباسات | 15 | 15 |
  | الجداول | 14 | 14 |

- لا يتسرّب أي LaTeX خام إلى الناتج: أوامر TeX منخفضة المستوى (`\def`, `\hbox`,
  `\raise`, `\char`) وتوجيهات تنسيق الصفحة (`\newpage`, `\suppressfloats`)
  تُستهلك أو تُترجم، بما في ذلك الرياضيات داخل تعليقات الكود ومداخل الفهرس.
- استثناء واحد مقصود: `foot:function-decl-vs-lambda` (3 مواضع) يشير إلى حاشية
  عن *hoisting* في JavaScript حُذفت عند نقل الكتاب إلى Python، فلا هدف لها في
  هذه النسخة أصلًا؛ تظهر كعلامة استفهام حمراء كما تظهر `??` في بناء LaTeX.
